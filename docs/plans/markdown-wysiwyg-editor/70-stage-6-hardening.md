# Stage 6 — 보안 / 폐쇄망 / 회귀

## 목표
편집·저장 기능을 출시 가능 상태로 굳힌다. 쓰기 권한 경계 재검증, 폐쇄망(번들-only) 회귀, 대용량/엣지 가드,
전체 테스트 매트릭스, 완료 조건(DoD)을 확정한다.

## 작업
1. **쓰기 권한 경계 재검증**:
   - read와 write가 **동일한 root/realpath 검증**을 공유하는지 코드 레벨 재확인(Stage 0 회귀 방지).
   - 편집 진입 자체가 authorizedRoots 안 `.md`에만 노출되는지(외부/읽기전용 게이트) 재확인.
   - `grantedDirs`(사용자가 명시적으로 연 외부 폴더) 쓰기 정책 문서화 — 허용/차단 명시.
2. **폐쇄망 회귀**: OS 방화벽 전면 차단 후 편집/수식/Mermaid/이미지/저장 전 시나리오 재실행 → 외부 fetch 0 확인.
   Milkdown/KaTeX CSS·폰트/Mermaid가 모두 번들에서 로드되는지 네트워크 패널/프록시로 검증.
3. **대용량/엣지 가드**:
   - 50MB 상한(읽기/쓰기 동일) 동작, 초과 시 편집 비활성.
   - 매우 큰 문서 편집 성능(타이핑 지연) 측정·허용 기준.
   - 빈 파일/BOM/CRLF·LF 혼용 줄바꿈 처리(줄바꿈 정책 명시: 보존 우선).
4. **테스트 매트릭스**(아래) 작성·통과.
5. **문서/회귀 노트**: file-viewer-panel 계획의 "파일 편집=비목표"가 본 계획으로 해제되었음을 상호 참조.

## 테스트 매트릭스
| 영역 | 테스트 |
|---|---|
| 보안(IPC) | root 안/밖, `..` 탈출, symlink, 확장자, 크기, mtime 충돌 |
| 라운드트립 | frontmatter/표/중첩목록/코드펜스/수식/mermaid/HTML 스냅샷 |
| 저장 흐름 | dirty 토글, 저장 성공/실패, 닫기/전환 가드 |
| 충돌 | 외부 변경 후 저장 → 충돌 UI 분기 |
| 폐쇄망 | 차단 환경 전 기능 외부 fetch 0 |
| 회귀 | 보기 모드(`MessageMarkdown`) 무변화, 다른 뷰어(code/csv/pdf 등) 무영향 |
| i18n/IME | 메뉴 번역, 한글 조합 입력 |

## 완료 조건 (DoD)
- [ ] 사용자가 패널에서 `.md`를 WYSIWYG로 편집하고 디스크에 저장 가능.
- [ ] 보기 모드와 다른 file-viewer 뷰어에 회귀 없음.
- [ ] 워크스페이스/grantedDirs 밖 쓰기 차단(단위 테스트로 고정).
- [ ] frontmatter·수식·Mermaid·HTML 라운드트립이 허용 범위 내(스냅샷 통과).
- [ ] 폐쇄망에서 전 기능 동작(외부 fetch 0).
- [ ] 외부 변경 충돌이 안전하게 처리됨.
- [ ] 미저장 변경 손실 방지 가드 동작.

## 롤백
최종 게이트는 `MarkdownViewer`의 편집 토글 노출 플래그. 문제 발생 시 플래그 off로 보기 전용 즉시 복귀
(IPC/에디터 코드는 남되 진입점만 차단).
