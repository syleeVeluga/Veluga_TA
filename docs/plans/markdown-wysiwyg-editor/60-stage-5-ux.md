# Stage 5 — 작성 UX 폴리시

## 목표
"문서 작성하듯" 경험을 완성한다. 슬래시 메뉴·블록 핸들·인라인 툴바·링크/이미지·단축키·플레이스홀더·접근성으로
일반 사용자가 마크다운 문법을 몰라도 작성/편집할 수 있게 한다.

## 작업
1. **슬래시 메뉴** (`@milkdown/plugin-slash`): `/`로 제목/목록/체크박스/표/코드/인용/구분선/수식/mermaid 삽입.
   메뉴 항목 라벨은 i18n(`react-i18next`) 적용(앱이 이미 사용 중).
2. **블록 핸들** (`@milkdown/plugin-block`): 블록 드래그 이동·삭제·추가 핸들.
3. **인라인 툴바**: 선택 텍스트에 볼드/이탤릭/코드/링크 툴바(plugin 또는 경량 커스텀).
4. **링크/이미지**:
   - 링크 삽입/편집 UI. 보기 측의 링크 정규화·`file://`/외부 링크 처리 정책과 일관.
   - 이미지: 로컬 경로 표시. **에디터 내 이미지 표시는 file-viewer의 read/grant 권한 경계 안에서만**(임의 경로 로드 금지).
5. **단축키**: 표준 마크다운 단축키(`#`, `-`, `>`, ``` ``` ```, `**`)와 `Cmd/Ctrl+B/I/K`, 저장 `Cmd/Ctrl+S`.
   [FileViewerPanel](../../../packages/cowork-core/src/renderer/features/file-viewer/FileViewerPanel.tsx)의 Esc/`Cmd+\`와 충돌 회피.
6. **플레이스홀더/포커스**: 빈 문단 placeholder, 진입 시 포커스, 스크롤 위치 보존.
7. **접근성/테마**: 키보드 내비게이션, 다크모드 토큰 일치, 한글 IME 조합 입력 안정성 확인.
8. **(검토) Crepe 차용**: `@milkdown/crepe`의 toolbar/slash/block 구현을 부분 차용할지, 조립형 유지할지 이 단계에서 결정.

## 영향 파일
- 수정: `editor/milkdown-config.ts`(slash/block/toolbar 등록), `editor/MilkdownEditor.tsx`(UI 연결), `editor/theme.ts`
- 수정: `package.json`(`@milkdown/plugin-slash`, `@milkdown/plugin-block` 등)
- i18n 리소스에 메뉴/툴바 문자열 추가

## 검증
| 항목 | 확인 |
|---|---|
| 슬래시 메뉴 | 블록 삽입 전 항목 동작 |
| 블록 핸들 | 드래그 이동/삭제 |
| 인라인 툴바 | 볼드/이탤릭/코드/링크 |
| 링크/이미지 | 권한 경계 내에서만 로드 |
| 단축키 | 마크다운/포맷/저장, 패널 단축키 무충돌 |
| IME | 한글 조합 입력 중 깨짐 없음 |
| 다크모드 | 토큰 일치 |
